# Cofre de Credenciais
 projeto desenvolvimento em java como parte dos neus estudos de lógica de programção e manipulação de stings. O sistema simula o cadastro de credenciais de um usuário e valida a segurança da senha informada.

## funcionalidades

* ** Cadastro de Usuário:** Leitura de nome de usuário e senha via terminal.
* ** Validação de Força de senha:** Verifica automaticamente se a senha atende aos requisitos mínino de segurança.
* Mínino de 8 caracteres.
* Pelo menos uma letra maiúscula ('A-Z')
* Pelo menos um número ('0-9')
* **Feedback Detalhado:** Informa ao usuário exatamente quasi critérios estão faltando caso a senha seja consirada fraca.
## TECNOLOGIAS UTILIZADAS 
* ** JAVA** (JDK)
* **Scanner** (Entrada de dados via console)
* **Expressões Regulares (Regex)** para verificação de caracteres
